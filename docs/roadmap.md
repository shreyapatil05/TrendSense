# Roadmap

1. Run collection weekly and retain at least eight weeks.
2. Mature 1-day and 3-day outcomes.
3. Execute walk-forward baseline comparison and error analysis.
4. Freeze a version, then tune weights manually on development folds only.
5. Ablate MiniLM semantic validation to measure its contribution.
6. Add a lightweight statistical model only when labels are sufficient.
7. Consider RAG only after retrieval quality can be measured.

Do not add more agents until evidence shows a missing responsibility.
