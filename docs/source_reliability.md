# Source reliability

Initial transparent priors are Trends 0.90, NewsAPI 0.75, YouTube 0.70, RSS 0.70, Wikipedia 0.65, Autocomplete 0.60, unknown 0.50. They are not learned truth.

Trends represents normalized search interest. YouTube represents content, not purchases. News and RSS represent editorial coverage. Wikipedia represents mainstream attention. Autocomplete represents suggested intent. Marketplace HTML is a fragile presence proxy, not sales validation.

Once forecasts mature, source-removal ablations can justify revised versioned weights on later folds.
